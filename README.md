# Naam Japa

A personal iPhone app for naam japa reminders: repeating reminders with vibration, a lotus that blooms on the home screen, and a 108-bead mala ring on the alert screen over your own wallpaper.

Built with Expo (SDK 54). To get the app file, open the **Actions** tab, choose **Build iPhone app**, and press **Run workflow**. When it finishes, download `NaamJapa-ipa` from the **Artifacts** section of the run.
